# English / international RSS feed list for a daily news watch.
# Format: Name | URL   (blank lines and lines starting with # are ignored)
#
# The script downloads each feed with a browser User-Agent then parses the bytes,
# which tolerates mislabelled feeds (Content-Type text/html). Check feeds-digest.log.
#
# To use: copy this file to feeds.txt in the same folder, then edit freely.
#   cp feeds.en.example.txt feeds.txt
#
# These mirror the categories of feeds.fr.example.txt with English/international
# sources. Some (NYT, FT, The Economist, WSJ) are paywalled — the feed still gives
# you titles and blurbs, which is enough for a briefing.
